# Конспекты лекций

Здесь лежат мои конспекты лекций по университетским предметам. Каждая лекция — это отдельный `.md` файл с оформленным текстом и приложенными фотографиями оригинальных записей. **(пока без фото, всё будет дорабатываться)**


## Как просматривать конспекты

Для полноценного просмотра (с формулами, таблицами, оглавлением и удобной навигацией) используйте VS Code с расширением **Markdown Preview Enhanced**.

**Установка:**

1. Скачайте и установите [VS Code](https://code.visualstudio.com/).
2. Откройте панель расширений: `Ctrl+Shift+X` (Windows/Linux) или `Cmd+Shift+X` (Mac).
3. В поиске введите `Markdown Preview Enhanced`.
4. Установите расширение.
5. Перезагрузите окно: `Ctrl+Shift+P` → `Reload Window`.

**Просмотр:**

1. Откройте папку с конспектами в VS Code (`File → Open Folder`).
2. Откройте нужный `.md` файл.
3. Нажмите `Ctrl+Shift+v` (или `Cmd+Shift+K` на Mac) — откроется отдельная вкладка.
4. Правки в `.md` файле будут сразу отражаться в предпросмотре.

**Полезно:**

- `Ctrl+Shift+S` — синхронизировать позицию курсора в редакторе и место в предпросмотре.
- Правый клик → **Export** — экспорт конспекта в PDF или HTML.
