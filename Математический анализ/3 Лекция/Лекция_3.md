# ЛЕКЦИЯ №3. ПРЕДЕЛ ФУНКЦИИ В ТОЧКЕ

## 1. Определение предела функции в точке

### 1.1. Определение по Гейне (на языке последовательностей)

Пусть функция $y = f(x)$ определена в некоторой окрестности точки $x_0$, кроме, быть может, самой точки $x_0$.

**Определение 1 (по Гейне).** Число $A$ называется **пределом функции** $y = f(x)$ в точке $x_0$ (или при $x \to x_0$), если для любой последовательности допустимых значений аргумента $x_n, n \in \mathbb{N}$ ($x_n \neq x_0$), сходящейся к $x_0$ (т.е. $\lim\limits_{n \to \infty} x_n = x_0$), последовательность соответствующих значений функции $f(x_n), n \in \mathbb{N}$, сходится к числу $A$ (т.е. $\lim\limits_{n \to \infty} f(x_n) = A$).

В этом случае пишут:
$$\lim_{x \to x_0} f(x) = A \quad \text{или} \quad f(x) \to A \text{ при } x \to x_0.$$

**Геометрический смысл предела функции:** $\lim\limits_{x \to x_0} f(x) = A$ означает, что для всех точек $x$, достаточно близких к точке $x_0$, соответствующие значения функции как угодно мало отличаются от числа $A$.

---

### 1.2. Определение по Коши (на «языке $\varepsilon$-$\delta$»)

**Определение 2.** Число $A$ называется **пределом функции** в точке $x_0$ (или при $x \to x_0$), если для любого положительного числа $\varepsilon$ найдется такое положительное число $\delta$, что для всех $x \neq x_0$, удовлетворяющих неравенству $|x - x_0| < \delta$, выполняется неравенство $|f(x) - A| < \varepsilon$.

Записывают $\lim\limits_{x \to x_0} f(x) = A$. Это определение коротко можно записать так:
$$(\forall \varepsilon > 0 \; \exists \delta > 0 \; \forall x : \underbrace{|x - x_0| < \delta, \; x \neq x_0}_{\text{или } 0 < |x - x_0| < \delta} \implies |f(x) - A| < \varepsilon) \iff \lim_{x \to x_0} f(x) = A.$$

**Геометрический смысл предела функции:** $A = \lim\limits_{x \to x_0} f(x)$, если для любой $\varepsilon$-окрестности точки $A$ найдется такая $\delta$-окрестность точки $x_0$, что для всех $x \neq x_0$ из этой $\delta$-окрестности соответствующие значения функции $f(x)$ лежат в $\varepsilon$-окрестности точки $A$. Иными словами, точки графика функции $y = f(x)$ лежат внутри полосы шириной $2\varepsilon$, ограниченной прямыми $y = A + \varepsilon$, $y = A - \varepsilon$. Очевидно, что величина $\delta$ зависит от выбора $\varepsilon$, поэтому пишут $\delta = \delta(\varepsilon)$.

---

## 2. Односторонние пределы

**Число $A_1$** называется **пределом функции** $y = f(x)$ **слева** в точке $x_0$, если для любого числа $\varepsilon > 0$ существует число $\delta = \delta(\varepsilon) > 0$ такое, что при $x \in (x_0 - \delta; x_0)$, выполняется неравенство $|f(x) - A_1| < \varepsilon$. Предел слева записывают так: $\lim\limits_{x \to x_0 - 0} f(x) = A_1$ или коротко: $f(x_0 - 0) = A_1$ (обозначение Дирихле).

Аналогично определяется **предел функции справа**, запишем его с помощью символов:
$$(\forall \varepsilon > 0 \; \exists \delta = \delta(\varepsilon) \; \forall x \in (x_0; x_0 + \delta) \implies |f(x) - A_2| < \varepsilon) \iff \lim_{x \to x_0 + 0} f(x) = A_2.$$

Коротко предел справа обозначают $f(x_0 + 0) = A_2$.

---

## 3. Предел функции при $x \to \infty$

Пусть функция $y = f(x)$ определена в промежутке $(-\infty; \infty)$. Число $A$ называется **пределом функции** $f(x)$ **при** $x \to \infty$, если для любого положительного числа $\varepsilon$ существует такое число $M = M(\varepsilon) > 0$, что при всех $x$, удовлетворяющих неравенству $|x| > M$ выполняется неравенство $|f(x) - A| < \varepsilon$. Коротко это определение можно записать так:
$$(\forall \varepsilon > 0 \; \exists M > 0 \; \forall x : |x| > M \implies |f(x) - A| < \varepsilon) \iff \lim_{x \to \infty} f(x) = A.$$

Если $x \to +\infty$, то пишут $A = \lim\limits_{x \to +\infty} f(x)$, если $x \to -\infty$, то — $A = \lim\limits_{x \to -\infty} f(x)$.

**Геометрический смысл** этого определения таков: для $\forall \varepsilon > 0 \; \exists M > 0$, что при $x \in (-\infty; -M)$ или $x \in (M; +\infty)$ соответствующие значения функции $f(x)$ попадают в $\varepsilon$-окрестность точки $A$, т.е. точки графика лежат в полосе шириной $2\varepsilon$, ограниченной прямыми $y = A + \varepsilon$ и $y = A - \varepsilon$.

## 4. Примеры вычисления и доказательства пределов

### Пример 1. Доказать, что $\lim\limits_{x \to 0} (3x - 2) = -2$

**Решение (по Коши):**

Шаг 1. Запишем определение предела: $\forall \varepsilon > 0 \; \exists \delta > 0$ такое, что для всех $x$, удовлетворяющих $0 < |x - 0| < \delta$ (или $0 < |x| < \delta$), выполняется $|f(x) - A| < \varepsilon$.

Шаг 2. Подставим $f(x) = 3x - 2$ и $A = -2$:
$$|3x - 2 - (-2)| < \varepsilon \implies |3x| < \varepsilon \implies |x| < \frac{\varepsilon}{3}.$$

Шаг 3. Выберем $\delta = \frac{\varepsilon}{3}$. Тогда для любого $\varepsilon > 0$ при $|x| < \delta$ выполняется $|f(x) - A| < \varepsilon$, что и требовалось доказать.

_Примечание:_ В лекции также приведена иллюстрация частного случая: если $\varepsilon = 3$, то $\delta = 1$. Тогда при $|x| < 1$ имеем $|f(x) - (-2)| = |3x| < 3$, что соответствует определению.

---

### Пример 2. Доказать, что $\lim\limits_{x \to 3} x^2 = 9$

**Решение (по Коши):**

Шаг 1. Запишем определение: $\forall \varepsilon > 0 \; \exists \delta > 0$ такое, что для всех $x$, удовлетворяющих $0 < |x - 3| < \delta$, выполняется $|x^2 - 9| < \varepsilon$.

Шаг 2. Преобразуем неравенство:
$$|x^2 - 9| = |(x - 3)(x + 3)| = |x - 3| \cdot |x + 3| < \varepsilon.$$

Шаг 3. Найдем оценку для $|x + 3|$. Поскольку $x \to 3$, можно считать, что $x$ находится в окрестности точки 3, например, $|x - 3| < 1$. Тогда $x \in (2; 4)$, следовательно, $|x + 3| < 7$. Тогда:
$$|x - 3| \cdot |x + 3| < 7 \cdot |x - 3| < \varepsilon \implies |x - 3| < \frac{\varepsilon}{7}.$$

Шаг 4. Выберем $\delta = \min\left(1, \frac{\varepsilon}{7}\right)$. Тогда для любого $\varepsilon > 0$ при $0 < |x - 3| < \delta$ выполняется $|x^2 - 9| < \varepsilon$.

_(В лекции используется упрощенная оценка $\delta = \frac{\varepsilon}{6}$, полученная при допущении, что $x$ близко к 3 и $|x + 3| \approx 6$.)_

---

### Пример 3. Доказать, что $\lim\limits_{x \to 3} (2x - 1) = 5$

**Решение:**

Возьмем произвольное $\varepsilon > 0$, найдем $\delta = \delta(\varepsilon) > 0$ такое, что для всех $x$, удовлетворяющих неравенству $|x - 3| < \delta$, выполняется неравенство $|(2x - 1) - 5| < \varepsilon$, т.е. $|x - 3| < \frac{\varepsilon}{2}$.

Взяв $\delta = \frac{\varepsilon}{2}$, видим, что для всех $x$, удовлетворяющих неравенству $|x - 3| < \delta \left( = \frac{\varepsilon}{2} \right)$, выполняется неравенство $|(2x - 1) - 5| < \varepsilon$. Следовательно, $\lim\limits_{x \to 3} (2x - 1) = 5$.

---

## 5. Доказательство несуществования предела

### Пример 4. Доказать, что не существует $\lim\limits_{x \to 0} \sin\frac{1}{x}$

**Решение (по Гейне):**

Шаг 1. Выберем последовательность $x_n = \frac{1}{\pi n}$, $n \in \mathbb{N}$. При $n \to \infty$ имеем $x_n \to 0$. Тогда:
$$f(x_n) = \sin\frac{1}{1/(\pi n)} = \sin(\pi n) = 0 \implies \lim_{n \to \infty} f(x_n) = 0.$$

Шаг 2. Выберем другую последовательность $x'_n = \frac{1}{\frac{\pi}{2} + \pi n}$, $n \to \infty$, $x'_n \to 0$. Тогда:
$$f(x'_n) = \sin\frac{1}{1/(\frac{\pi}{2} + \pi n)} = \sin\left(\frac{\pi}{2} + \pi n\right) = 1 \implies \lim_{n \to \infty} f(x'_n) = 1.$$

Шаг 3. Получили две последовательности, сходящиеся к 0, но соответствующие последовательности значений функции сходятся к разным пределам (0 и 1). По определению Гейне предел не существует.

---

### Пример 5. Доказать, что не существует $\lim\limits_{x \to 0} \operatorname{sign} x$, $x_0 = 0$

**Решение (по Гейне):**

Шаг 1. Рассмотрим последовательность $x_n = \frac{1}{n}$, $n \to \infty$, $\frac{1}{n} \to 0$. Тогда:
$$\lim_{n \to \infty} f(x_n) = \lim_{n \to \infty} \operatorname{sign}\left(\frac{1}{n}\right) = \lim_{n \to \infty} 1 = 1.$$

Шаг 2. Рассмотрим последовательность $x'_n = -\frac{1}{n}$, $n \to \infty$, $-\frac{1}{n} \to 0$. Тогда:
$$\lim_{n \to \infty} f(x'_n) = \lim_{n \to \infty} \operatorname{sign}\left(-\frac{1}{n}\right) = \lim_{n \to \infty} (-1) = -1.$$

Шаг 3. Пределы последовательностей значений функции различны ($1 \neq -1$), следовательно, предел функции в точке $x_0 = 0$ не существует.

---

## Выдержка из самых важных формул

1. **Определение предела по Коши:**
   $$\lim_{x \to x_0} f(x) = A \iff \forall \varepsilon > 0 \; \exists \delta > 0 \; \forall x: 0 < |x - x_0| < \delta \implies |f(x) - A| < \varepsilon.$$

2. **Определение предела по Гейне:**
   $$\lim_{x \to x_0} f(x) = A \iff \forall \{x_n\} \to x_0 \; (x_n \neq x_0) \implies f(x_n) \to A.$$

3. **Односторонние пределы:**
   - Слева: $\lim\limits_{x \to x_0 - 0} f(x) = A_1 \iff \forall \varepsilon > 0 \; \exists \delta > 0 \; \forall x \in (x_0 - \delta; x_0) \implies |f(x) - A_1| < \varepsilon$.
   - Справа: $\lim\limits_{x \to x_0 + 0} f(x) = A_2 \iff \forall \varepsilon > 0 \; \exists \delta > 0 \; \forall x \in (x_0; x_0 + \delta) \implies |f(x) - A_2| < \varepsilon$.

4. **Предел при $x \to \infty$:**
   $$\lim_{x \to \infty} f(x) = A \iff \forall \varepsilon > 0 \; \exists M > 0 \; \forall x: |x| > M \implies |f(x) - A| < \varepsilon.$$
