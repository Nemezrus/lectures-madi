# Лекция №2: Числовые последовательности и их пределы

## 1. Определение числовой последовательности

**Числовая последовательность** — это функция, заданная на множестве натуральных чисел \(\mathbb{N}\):
\[
x_n = f(n), \quad n \in \mathbb{N}
\]

Кратко последовательность обозначается как \(\{x_n\}\) или \(x_n\). Число \(x_1\) называется **первым членом**, \(x_2\) — вторым, а \(x_n\) — **общим** или \(n\)-м членом последовательности.

### Примеры последовательностей:
1. \(\{x_n\} = \left\{1; \frac{1}{2}; \frac{1}{3}; \dots; \frac{1}{n}; \dots\right\}\), где \(x_n = \frac{1}{n}\)
2. \(\{y_n\} = \{-1; 2; -3; 4; \dots; (-1)^n \cdot n; \dots\}\)
3. \(\{u_n\} = \left\{0; \frac{1}{2}; \frac{2}{3}; \frac{3}{4}; \frac{4}{5}; \dots; \frac{n-1}{n}; \dots\right\}\), \(n \in \mathbb{N}\)

---

## 2. Способы задания последовательностей

### 2.1. Рекуррентный способ
Задается начальный элемент \(x_1\) (и иногда несколько первых), а также правило нахождения \(n\)-го элемента через предыдущие:
\[
x_n = f(x_{n-1})
\]
Например, \(x_2 = f(x_1)\), \(x_3 = f(x_2)\) и т.д.

**Примеры:**
1. **Числа Фибоначчи**:
   \[
   x_{n+2} = x_{n+1} + x_n, \quad x_1 = 1, \; x_2 = 1
   \]
   \[
   x_3 = 1 + 1 = 2, \quad x_4 = 2 + 1 = 3, \quad x_5 = 3 + 2 = 5, \dots
   \]
   Последовательность: \(1; 1; 2; 3; 5; \dots\)

2. **Арифметическая прогрессия**:
   \[
   a_{n+1} = a_n + d, \quad a_1 = 2, \; d = 3
   \]
   \[
   2; 5; 8; 11; \dots
   \]

3. **Пример из фото 4**:
   \[
   b_{n+1} = b_n + (2n + 1), \quad b_1 = 1
   \]
   \[
   b_2 = 1 + (2 \cdot 1 + 1) = 4, \quad b_3 = 4 + (4 + 1) = 9
   \]
   Последовательность: \(1; 4; 9; 16; \dots\) (квадраты натуральных чисел).

---

## 3. Свойства последовательностей: монотонность и ограниченность

### 3.1. Монотонность

Последовательность **строго возрастает**, если \(x_{n+1} > x_n\) для всех \(n \in \mathbb{N}\). Для проверки нужно рассмотреть разность \(x_{n+1} - x_n\) и показать, что она положительна.

**Пример 1:** \(x_n = 2n + 1\)
\[
x_{n+1} - x_n = 2(n+1) + 1 - (2n+1) = 2n + 2 + 1 - 2n - 1 = 2 > 0
\]
Значит, \(x_{n+1} > x_n\) — последовательность **строго возрастает**.

**Пример 2:** \(x_n = \frac{(-1)^n}{n}\)
Последовательность: \(-1; \frac{1}{2}; -\frac{1}{3}; \dots\) — **не является монотонной**.

**Пример 3:** \(x_n = \frac{1}{n^2}\) — **убывает** (строго убывающая).

**Пример 4:** \(x_n = [\sqrt{n}]\) (целая часть корня)
Последовательность: \(1; 1; 1; 2; 2; 2; 2; 2; 3; \dots\) — **не является монотонной**.

### 3.2. Пример исследования монотонности (фото 8)

Исследовать последовательность \(x_n = \frac{n}{2n+1}\):

**Шаг 1.** Найдем разность \(x_{n+1} - x_n\):
\[
x_{n+1} - x_n = \frac{n+1}{2(n+1)+1} - \frac{n}{2n+1} = \frac{n+1}{2n+3} - \frac{n}{2n+1}
\]

**Шаг 2.** Приведем к общему знаменателю:
\[
= \frac{(n+1)(2n+1) - n(2n+3)}{(2n+3)(2n+1)}
\]

**Шаг 3.** Раскроем скобки в числителе:
\[
= \frac{2n^2 + n + 2n + 1 - 2n^2 - 3n}{(2n+3)(2n+1)} = \frac{1}{(2n+3)(2n+1)}
\]

**Шаг 4.** Так как знаменатель положителен при всех \(n \in \mathbb{N}\), то \(x_{n+1} - x_n > 0\). Следовательно, \(x_{n+1} > x_n\), то есть последовательность **строго возрастает**.

## 4. Предел числовой последовательности

### 4.1. Определение предела

**Число \(a\) называется пределом последовательности \(\{x_n\}\)**, если для любого положительного числа \(\varepsilon\) найдется такое натуральное число \(N\), что при всех \(n > N\) выполняется неравенство:
\[
|x_n - a| < \varepsilon
\]

Обозначение:
\[
\lim_{n \to \infty} x_n = a \quad \text{или} \quad x_n \to a
\]

Говорят, что последовательность **сходится** к \(a\).

Короткая запись определения:
\[
(\forall \varepsilon > 0 \; \exists N : \; \forall n > N \implies |x_n - a| < \varepsilon) \iff \lim_{n \to \infty} x_n = a
\]

### 4.2. Теорема о единственности предела

**Теорема.** Последовательность не может иметь более одного предела.

**Доказательство.**
Предположим, что последовательность \(\{x_n\}\) имеет два предела \(a\) и \(b\), не равные друг другу: \(x_n \to a\), \(x_n \to b\), причем \(a \neq b\).

Тогда по определению для любого \(\varepsilon > 0\) существует такое \(N\), что при \(n > N\):
\[
|a - x_n| < \frac{\varepsilon}{2}
\]
\[
|b - x_n| < \frac{\varepsilon}{2}
\]

Рассмотрим выражение:
\[
|a - b| = |(a - x_n) + (x_n - b)| \le |a - x_n| + |x_n - b| < \frac{\varepsilon}{2} + \frac{\varepsilon}{2} = \varepsilon
\]

Так как \(\varepsilon\) — любое число, то \(|a - b| = 0\), то есть \(a = b\). Теорема доказана.

## 5. Примеры вычисления пределов по определению

### Пример 1 (фото 1): \(\lim_{n \to \infty} \frac{2n+1}{4n-1} = \frac{1}{2}\)

**Шаг 1.** Запишем условие по определению: для любого \(\varepsilon > 0\) нужно найти \(N\), такое что при \(n > N\):
\[
\left| \frac{2n+1}{4n-1} - \frac{1}{2} \right| < \varepsilon
\]

**Шаг 2.** Упростим выражение под модулем:
\[
\left| \frac{2n+1}{4n-1} - \frac{1}{2} \right| = \left| \frac{2(2n+1) - (4n-1)}{2(4n-1)} \right| = \left| \frac{4n+2 - 4n + 1}{2(4n-1)} \right| = \left| \frac{3}{2(4n-1)} \right|
\]

**Шаг 3.** Так как \(n \ge 1\), то \(4n - 1 > 0\), поэтому модуль можно убрать:
\[
\frac{3}{2(4n-1)} < \varepsilon
\]

**Шаг 4.** Решим неравенство относительно \(n\):
\[
4n - 1 > \frac{3}{2\varepsilon}
\]
\[
4n > \frac{3}{2\varepsilon} + 1
\]
\[
n > \frac{3}{8\varepsilon} + \frac{1}{4}
\]

**Шаг 5.** Следовательно, можно взять:
\[
N = \left[ \frac{3}{8\varepsilon} + 1 \right] + 1
\]
(где квадратные скобки означают целую часть числа).

**Шаг 6.** Проверка для \(\varepsilon = 0{,}03\):
\[
n > \frac{3}{8 \cdot 0{,}03} + \frac{1}{4} = \frac{3}{0{,}24} + 0{,}25 = 12{,}5 + 0{,}25 = 12{,}75
\]
То есть \(N = 13\).

### Пример 2 (фото 2 и 3): \(\lim_{n \to \infty} \frac{3n+2}{n+1} = 3\)

**Шаг 1.** Условие:
\[
\left| \frac{3n+2}{n+1} - 3 \right| < \varepsilon
\]

**Шаг 2.** Упростим:
\[
\left| \frac{3n+2 - 3(n+1)}{n+1} \right| = \left| \frac{3n+2 - 3n - 3}{n+1} \right| = \left| \frac{-1}{n+1} \right| = \frac{1}{n+1}
\]

**Шаг 3.** Неравенство:
\[
\frac{1}{n+1} < \varepsilon \implies n+1 > \frac{1}{\varepsilon} \implies n > \frac{1}{\varepsilon} - 1
\]

**Шаг 4.** Отсюда \(N(\varepsilon) = \left[ \frac{1}{\varepsilon} - 1 \right] + 1\).

**Шаг 5.** Проверка для \(\varepsilon = 1\):
\[
N(1) = \left[ 1 - 1 \right] + 1 = 1
\]
При \(n > 1\) (например, \(n = 2\)): \(\frac{1}{3} < 1\) — выполняется.

**Шаг 6.** Проверка для \(\varepsilon = 0{,}01\):
\[
N(0{,}01) = \left[ \frac{1}{0{,}01} - 1 \right] + 1 = [100 - 1] + 1 = 100
\]
При \(n = 100\): \(\frac{1}{101} < 0{,}01\) — выполняется.

---

## Выдержка основных формул

**Определение предела:**
\[
\lim_{n \to \infty} x_n = a \iff \forall \varepsilon > 0 \; \exists N : \forall n > N \implies |x_n - a| < \varepsilon
\]

**Единственность предела:** последовательность не может иметь более одного предела.

**Рекуррентная формула Фибоначчи:**
\[
x_{n+2} = x_{n+1} + x_n, \quad x_1 = 1, \; x_2 = 1
\]

**Арифметическая прогрессия:**
\[
a_{n+1} = a_n + d
\]

**Исследование монотонности:** если \(x_{n+1} - x_n > 0\) для всех \(n \in \mathbb{N}\), то последовательность строго возрастает.
