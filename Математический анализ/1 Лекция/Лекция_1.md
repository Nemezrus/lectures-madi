## 1. Основы теории множеств

**Определение (Множество).** Под **множеством** понимают совокупность некоторых объектов, объединённых по какому-либо признаку.
*Пример:* множество студентов группы, множество корней уравнения, множество натуральных чисел.

**Определение (Элемент множества).** Объекты, из которых состоит множество, называют его **элементами**.

**Обозначения:**
*   \(x \in X\) — элемент \(x\) принадлежит множеству \(X\).
*   \(x \notin X\) (или \(x \bar{\in} X\)) — элемент \(x\) не принадлежит множеству \(X\).

**Определение (Пустое множество).** Множество, не содержащее ни одного элемента, называется **пустым** и обозначается символом \(\varnothing\).

**Способы записи множеств:**
Элементы множества записывают в фигурных скобках, внутри которых они перечислены (если это возможно), либо указано общее свойство, которым обладают все элементы данного множества.
*   *Пример 1:* \(A = \{1, 3, 15\}\) — множество \(A\) состоит из трёх чисел: 1, 3 и 15.
*   *Пример 2:* \(A = \{x : 0 \le x \le 2\}\) — множество \(A\) состоит из всех действительных чисел, удовлетворяющих неравенству \(0 \le x \le 2\).

## 2. Операции над множествами и логические символы

**Определение (Подмножество).** Множество \(A\) называется **подмножеством** множества \(B\), если каждый элемент множества \(A\) является элементом множества \(B\).
*   Обозначение: \(A \subset B\) («\(A\) включено в \(B\)») или \(B \supset A\) («множество \(B\) включает в себя множество \(A\)»).

**Определение (Равенство множеств).** Множества \(A\) и \(B\) **равны** (совпадают), \(A = B\), если \(A \subset B\) и \(B \subset A\). Другими словами, множества, состоящие из одних и тех же элементов, называются равными.

**Определение (Объединение).** **Объединением** (или суммой) множеств \(A\) и \(B\) называется множество, состоящее из элементов, каждый из которых принадлежит хотя бы одному из этих множеств.
*   Обозначение: \(A \cup B\) (или \(A + B\)).
*   Формально: \(A \cup B = \{x : x \in A \text{ или } x \in B\}\).
*   *Пример:* \(A = \{1, 2, 3\}\), \(B = \{1, 2, 3, 5, 6\} \implies A \cup B = \{1, 2, 3, 5, 6\}\).

**Определение (Пересечение).** **Пересечением** (или произведением) множеств \(A\) и \(B\) называется множество, состоящее из элементов, каждый из которых принадлежит и множеству \(A\), и множеству \(B\).
*   Обозначение: \(A \cap B\) (или \(A \cdot B\)).
*   Формально: \(A \cap B = \{x : x \in A \text{ и } x \in B\}\).

**Логические символы:**
*   \(\alpha \implies \beta\) — «из предложения \(\alpha\) следует предложение \(\beta\)»;
*   \(\alpha \iff \beta\) — «предложения \(\alpha\) и \(\beta\) равносильны» (из \(\alpha\) следует \(\beta\), и из \(\beta\) следует \(\alpha\));
*   \(\forall\) — «для любого», «для всякого»;
*   \(\exists\) — «существует», «найдётся»;
*   \(:\) — «имеет место», «такое что»;
*   \(\mapsto\) — «соответствие».

*Примеры:*
1) \(\forall x \in A : \alpha\) означает: «для всякого элемента \(x \in A\) имеет место предложение \(\alpha\)».
2) \((x \in A \cup B) \iff (x \in A \text{ или } x \in B)\) — определяет объединение множеств.

## 3. Числовые множества и промежутки

**Определение (Числовые множества).** Множества, элементами которых являются числа, называются **числовыми**. Примеры числовых множеств:
*   \(\mathbb{N} = \{1; 2; 3; \dots; n; \dots\}\) — множество натуральных чисел;
*   \(\mathbb{Z}_0 = \{0; 1; 2; \dots; n; \dots\}\) — множество целых неотрицательных чисел;
*   \(\mathbb{Z} = \{0; \pm 1; \pm 2; \dots; \pm n; \dots\}\) — множество целых чисел;
*   \(\mathbb{Q} = \left\{ \frac{m}{n} : m \in \mathbb{Z}, n \in \mathbb{N} \right\}\) — множество рациональных чисел;
*   \(\mathbb{R}\) — множество действительных чисел.

Между этими множествами существует соотношение:
\[
 \mathbb{N} \subset \mathbb{Z}_0 \subset \mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R} 
\]

**Числовые промежутки (интервалы):**
Пусть \(a\) и \(b\) — действительные числа, причём \(a < b\).
*   \([a; b] = \{x : a \le x \le b\}\) — **отрезок** (сегмент, замкнутый промежуток);
*   \((a; b) = \{x : a < x < b\}\) — **интервал** (открытый промежуток);
*   $
[a; b) = \{x : a \le x < b\}$ — **полуоткрытые интервалы**;
*   \((a; b] = \{x : a < x \le b\}\) — **полуоткрытые интервалы**.

Бесконечные интервалы (промежутки):
*   \((-\infty; b] = \{x : x \le b\}\);
*   \((-\infty; b) = \{x : x < b\}\);
*   \([a; +\infty) = \{x : x \ge a\}\);
*   \((a; +\infty) = \{x : x > a\}\);
*   \((-\infty; +\infty) = \{x : -\infty < x < +\infty\} = \mathbb{R}\).

**Определение (\(\varepsilon\)-окрестность).** Пусть \(x_0\) — любое действительное число (точка на числовой прямой). **Окрестностью** точки \(x_0\) называется любой интервал \((a; b)\), содержащий точку \(x_0\). В частности, интервал \((x_0 - \varepsilon, x_0 + \varepsilon)\), где \(\varepsilon > 0\), называется **\(\varepsilon\)-окрестностью** точки \(x_0\). Число \(x_0\) называется **центром**, а число \(\varepsilon\) — **радиусом**.

Если \(x \in (x_0 - \varepsilon; x_0 + \varepsilon)\), то выполняется неравенство \(x_0 - \varepsilon < x < x_0 + \varepsilon\), или, что то же, \(|x - x_0| < \varepsilon\). Выполнение последнего неравенства означает попадание точки \(x\) в \(\varepsilon\)-окрестность точки \(x_0\).

## 4. Функция

**Определение (Функция).** Пусть даны два непустых множества \(X\) и \(Y\). Соответствие \(f\), которое каждому элементу \(x \in X\) сопоставляет один и только один элемент \(y \in Y\), называется **функцией** и записывается \(y = f(x), x \in X\) или \(f : X \to Y\). Говорят ещё, что функция \(f\) **отображает** множество \(X\) на множество \(Y\).

*   Множество \(X\) называется **областью определения** функции \(f\) и обозначается \(D(f)\).
*   Множество всех \(y \in Y\) называется **множеством значений** функции \(f\) и обозначается \(E(f)\).

**Примеры нахождения области определения:**

*   **Пример 1.** Найти область определения \(f(x) = \frac{\ln(1+x)}{x^2-1}\).
    *   *Шаг 1.* Аргумент логарифма должен быть положительным: \(1+x > 0 \implies x > -1\).
    *   *Шаг 2.* Знаменатель не должен равняться нулю: \(x^2 - 1 \ne 0 \implies x \ne \pm 1\).
    *   *Шаг 3.* Объединяем условия: \(\begin{cases} x > -1 \\ x \ne 1 \end{cases}\) (условие \(x \ne -1\) поглощается \(x > -1\)).
    *   *Ответ:* \(D(f) = (-1; 1) \cup (1; +\infty)\).

*   **Пример 2.** Найти область определения \(f(x) = \sqrt{4-x^2} + \frac{1}{x}\).
    *   *Шаг 1.* Подкоренное выражение неотрицательно: \(4-x^2 \ge 0 \implies (2-x)(2+x) \ge 0 \implies x \in [-2; 2]\).
    *   *Шаг 2.* Знаменатель не равен нулю: \(x \ne 0\).
    *   *Шаг 3.* Пересекаем условия на числовой прямой.
    *   *Ответ:* \(D(f) = [-2; 0) \cup (0; 2]\).

*   **Пример 3.** Найти область определения \(f(x) = \arccos\left(\frac{x}{2} - 1\right)\).
    *   *Шаг 1.* Область значений арккосинуса: \(-1 \le \frac{x}{2} - 1 \le 1\).
    *   *Шаг 2.* Прибавим 1 ко всем частям: \(0 \le \frac{x}{2} \le 2\).
    *   *Шаг 3.* Умножим на 2: \(0 \le x \le 4\).
    *   *Ответ:* \(D(f) = [0; 4]\).

**Нахождение множества значений:**

*   **Пример 4.** Найти \(E(f)\) для \(f(x) = x^2 - 6x + 5\).
    *   *Шаг 1.* Выделим полный квадрат: \(x^2 - 6x + 5 = (x^2 - 6x + 9) - 9 + 5 = (x-3)^2 - 4\).
    *   *Шаг 2.* Так как \((x-3)^2 \ge 0\), то \((x-3)^2 - 4 \ge -4\).
    *   *Ответ:* \(E(f) = [-4; +\infty)\).

*   **Пример 5.** Найти \(E(f)\) для \(f(x) = 2 + 3\sin x\).
    *   *Шаг 1.* Известно, что \(-1 \le \sin x \le 1\).
    *   *Шаг 2.* Умножим на 3: \(-3 \le 3\sin x \le 3\).
    *   *Шаг 3.* Прибавим 2: \(-1 \le 2 + 3\sin x \le 5\).
    *   *Ответ:* \(E(f) = [-1; 5]\).

## 5. Способы задания и свойства функций

**Определение (Числовая функция).** Если элементами множеств \(X\) и \(Y\) являются действительные числа (т.е. \(X \subset \mathbb{R}\) и \(Y \subset \mathbb{R}\)), то функцию \(f\) называют **числовой функцией**. Переменная \(x\) называется **аргументом** или независимой переменной, а \(y\) — **функцией** или зависимой переменной.

**Способы задания функции:**
1.  **Аналитический способ:** функция задаётся в виде одной или нескольких формул (уравнений).
    *   *Примеры:* \(S = \pi R^2\); \(y = \begin{cases} x^2 + 1 & \text{при } x < 2 \\ x - 4 & \text{при } x \ge 2 \end{cases}\); \(y^2 - 4x = 0\).
2.  **Графический способ:** задаётся график функции.
    *   *График функции* \(y = f(x)\) — множество всех точек плоскости \(Oxy\), для каждой из которых \(x\) является значением аргумента, а \(y\) — соответствующим значением функции.
    *   *Пример:* графиком \(y = \sqrt{1 - x^2}\) является верхняя полуокружность радиуса \(R=1\) с центром в \(O(0;0)\).
    *   *Преимущество:* наглядность. *Недостаток:* неточность.
3.  **Табличный способ:** функция задаётся таблицей ряда значений аргумента и соответствующих значений функции (например, таблицы тригонометрических функций, логарифмические таблицы).

**Свойства функций:**

**Чётность/Нечётность:**
*   Функция \(y = f(x)\), определённая на множестве \(D\), называется **чётной**, если \(\forall x \in D\) выполняются условия \(-x \in D\) и \(f(-x) = f(x)\).
*   Функция называется **нечётной**, если \(\forall x \in D\) выполняются условия \(-x \in D\) и \(f(-x) = -f(x)\).
*   *График:* чётной функции симметричен относительно оси \(Oy\), нечётной — относительно начала координат.
*   *Примеры:* \(y = x^2\), \(y = \sqrt{1+x^2}\), \(y = \ln|x|\) — чётные; \(y = \sin x\), \(y = x^3\) — нечётные; \(y = x - 1\), \(y = \sqrt{x}\) — функции общего вида (не чётные и не нечётные).

**Монотонность:**
Пусть функция \(y = f(x)\) определена на множестве \(D\) и пусть \(D_1 \subset D\). Если для любых \(x_1, x_2 \in D_1\) из неравенства \(x_1 < x_2\) вытекает:
*   \(f(x_1) < f(x_2)\), то функция называется **возрастающей** на множестве \(D_1\);
*   \(f(x_1) \le f(x_2)\), то функция называется **неубывающей** на множестве \(D_1\);
*   \(f(x_1) > f(x_2)\), то функция называется **убывающей** на множестве \(D_1\);
*   \(f(x_1) \ge f(x_2)\), то функция называется **невозрастающей** на множестве \(D_1\).

Возрастающие, невозрастающие, убывающие и неубывающие функции на множестве \(D_1\) называются **монотонными** на этом множестве, а возрастающие и убывающие — **строго монотонными**. Интервалы, в которых функция монотонна, называются **интервалами монотонности**.

*   *Пример:* \(y = 2x + 1\) — строго монотонно возрастает.
*   *Пример:* \(y = \text{sign}\, x\) — неубывающая функция.
    \[
 \text{sign}\, x = \begin{cases} 1, & x > 0 \\ 0, & x = 0 \\ -1, & x < 0 \end{cases} 
\]

## Выдержка из самых важных формул и определений

1.  **Объединение и пересечение:** \(A \cup B = \{x : x \in A \text{ или } x \in B\}\); \(A \cap B = \{x : x \in A \text{ и } x \in B\}\).
2.  **Числовые множества:** \(\mathbb{N} \subset \mathbb{Z}_0 \subset \mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R}\).
3.  **Окрестность:** \(|x - x_0| < \varepsilon \iff x \in (x_0 - \varepsilon; x_0 + \varepsilon)\).
4.  **Функция:** \(f : X \to Y\), \(y = f(x)\); \(D(f)\) — область определения, \(E(f)\) — область значений.
5.  **Чётность:** \(f(-x) = f(x)\) (чётная); \(f(-x) = -f(x)\) (нечётная).
6.  **Монотонность:** \(x_1 < x_2 \implies f(x_1) < f(x_2)\) (строго возрастает); \(x_1 < x_2 \implies f(x_1) > f(x_2)\) (строго убывает).
