# Конспект лекций: Исследование функций и построение графиков

---

# 1. Максимум и минимум функции

**Определение.** Точка \(x_0\) называется **точкой максимума** функции \(y = f(x)\), если существует такая \(\delta\)-окрестность точки \(x_0\), что для всех \(x \neq x_0\) из этой окрестности выполняется неравенство:
\[
f(x) < f(x_0).
\]

Аналогично определяется **точка минимума**: \(x_0\) — точка минимума функции, если \(\exists \delta > 0\) такое, что \(\forall x : 0 < |x - x_0| < \delta \implies f(x) > f(x_0)\).

На рисунке \(x_1\) — точка минимума, а точка \(x_2\) — точка максимума функции \(y = f(x)\).

Значение функции в точке максимума (минимума) называется **максимумом (минимумом)** функции. Максимум (минимум) функции называется **экстремумом** функции.

---

# 2. Необходимое условие экстремума

**Теорема (необходимое условие экстремума).** Если дифференцируемая функция \(y = f(x)\) имеет экстремум в точке \(x_0\), то ее производная в этой точке равна нулю:
\[
f'(x_0) = 0.
\]

**Доказательство.**
Пусть, для определенности, \(x*0\) — точка максимума. Значит, в окрестности точки \(x_0\) выполняется неравенство \(f(x_0) > f(x_0 + \Delta x)\). Но тогда
\[
\frac{\Delta y}{\Delta x} = \frac{f(x_0 + \Delta x) - f(x_0)}{\Delta x} < 0, \text{ если } \Delta x > 0,
\]
и
\[
\frac{\Delta y}{\Delta x} > 0, \text{ если } \Delta x < 0.
\]
По условию теоремы производная
\[
f'(x_0) = \lim*{\Delta x \to 0} \frac{f(x_0 + \Delta x) - f(x_0)}{\Delta x}
\]
существует. Переходя к пределу при \(\Delta x \to 0\), получим \(f'(x_0) \ge 0\), если \(\Delta x < 0\), и \(f'(x_0) \le 0\), если \(\Delta x > 0\). Поэтому \(f'(x_0) = 0\).

**Геометрический смысл.** Геометрически равенство \(f'(x_0) = 0\) означает, что в точке экстремума дифференцируемой функции \(y = f(x)\) касательная к ее графику параллельна оси \(Ox\).

**Замечание.** Обратная теорема неверна, т. е. если \(f'(x_0) = 0\), то это не значит, что \(x_0\) — точка экстремума. Например, для функции \(y = x^3\) ее производная \(y' = 3x^2\) равна нулю при \(x = 0\), но \(x = 0\) не точка экстремума.

---

# 3. Критические точки

Существуют функции, которые в точках экстремума не имеют производной. Например, непрерывная функция \(y = |x|\) в точке \(x = 0\) производной не имеет, но точка \(x = 0\) — точка минимума.

Таким образом, непрерывная функция может иметь экстремум лишь в точках, где производная функции равна нулю или не существует. Такие точки называются **критическими**.

---

# 4. Достаточное условие экстремума

**Теорема (достаточное условие экстремума).** Если непрерывная функция \(y = f(x)\) дифференцируема в некоторой \(\delta\)-окрестности критической точки \(x_0\) и при переходе через нее (слева направо) производная \(f'(x)\) меняет знак с плюса на минус, то \(x_0\) есть точка максимума; с минуса на плюс, то \(x_0\) — точка минимума.

---

# 5. Правило исследования функции на экстремум

Исследовать функцию на экстремум означает найти все ее экстремумы. Из теорем вытекает следующее правило исследования функции на экстремум:

1. Найти критические точки функции \(y = f(x)\);
2. Выбрать из них лишь те, которые являются внутренними точками области определения функции;
3. Исследовать знак производной \(f'(x)\) слева и справа от каждой из выбранных критических точек;
4. В соответствии с теоремой (достаточное условие экстремума) выписать точки экстремума (если они есть) и вычислить значения функции в них.

### Правило нахождения наибольшего и наименьшего значений функции на \([a; b]\):

1. Найти критические точки функции на интервале \((a; b)\);
2. Вычислить значения функции в найденных критических точках;
3. Вычислить значения функции на концах отрезка, т. е. в точках \(x = a\) и \(x = b\);
4. Среди всех вычисленных значений функции выбрать наибольшее и наименьшее.

---

# 6. Возрастание (убывание) функции

**Теорема (достаточные условия).** Если функция \(f(x)\) дифференцируема на интервале \((a; b)\) и \(f'(x) > 0\) (\(f'(x) < 0\)) для \(\forall x \in (a; b)\), то эта функция возрастает (убывает) на интервале \((a; b)\).

**Доказательство.**
Пусть \(f'(x) > 0\). Возьмем точки \(x_1\) и \(x_2\) из интервала \((a; b)\), причем \(x_1 < x_2\). Применим к отрезку \([x_1; x_2]\) теорему Лагранжа:
\[
f(x_2) - f(x_1) = f'(c)(x_2 - x_1), \text{ где } c \in (x_1; x_2).
\]
По условию \(f'(c) > 0\), \(x_2 - x_1 > 0\). Следовательно, \(f(x_2) - f(x_1) > 0\) или \(f(x_2) > f(x_1)\), т. е. функция \(f(x)\) на интервале \((a; b)\) возрастает.

---

# 7. Выпуклость графика функции, точки перегиба

**Определение.** График дифференцируемой функции \(y = f(x)\) называется **выпуклым вниз** на интервале \((a; b)\), если он расположен выше любой ее касательной на этом интервале. График функции \(y = f(x)\) называется **выпуклым вверх** на интервале \((a; b)\), если он расположен ниже любой ее касательной на этом интервале.

Точка графика непрерывной функции \(y = f(x)\), отделяющая его части разной выпуклости, называется **точкой перегиба**.

**Теорема.** Если функция \(y = f(x)\) во всех точках интервала \((a; b)\) имеет отрицательную вторую производную, т. е. \(f''(x) < 0\), то график функции в этом интервале выпуклый вверх. Если же \(f''(x) > 0\) \(\forall x \in (a; b)\) — график выпуклый вниз.

**Теорема (достаточное условие существования точек перегиба).** Если вторая производная \(f''(x)\) при переходе через точку \(x_0\), в которой она равна нулю или не существует, меняет знак, то точка графика с абсциссой \(x_0\) есть точка перегиба.

---

# 8. Асимптоты графика функции

**Определение.** **Асимптотой** кривой называется прямая, расстояние до которой от точки, лежащей на кривой, стремится к нулю при неограниченном удалении от начала координат этой точки по кривой.

Асимптоты могут быть **вертикальными**, **наклонными** и **горизонтальными**.

Говорят, что прямая \(x = a\) является **вертикальной асимптотой** графика функции \(y = f(x)\), если \(\lim*{x \to a} f(x) = \infty\), или \(\lim*{x \to a-0} f(x) = \infty\), или \(\lim\_{x \to a+0} f(x) = \infty\).

Уравнение **наклонной асимптоты** будем искать в виде:
\[
y = kx + b.
\]
Коэффициенты вычисляются по формулам:
\[
k = \lim*{x \to \infty} \frac{y}{x},
\]
\[
b = \lim*{x \to \infty} (y - kx).
\]

---

# 9. Общая схема исследования и построения графика функции

1. Найти область определения функции.
2. Найти (если это можно) точки пересечения графика с осями координат.
3. Найти интервалы знакопостоянства функции (промежутки, на которых \(f(x) > 0\) или \(f(x) < 0\)).
4. Выяснить, является ли функция четной, нечетной или общего вида.
5. Найти асимптоты графика функции.
6. Найти интервалы монотонности функции.
7. Найти экстремумы функции.
8. Найти интервалы выпуклости и точки перегиба графика функции.

---

# 10. Примеры решения задач

### Пример 1. Исследование функции \(f(x) = \frac{\ln x}{x}\)

**Шаг 1.** Область определения: \(\mathcal{D}(f): x > 0\).

**Шаг 2.** Находим производную по правилу дифференцирования дроби:
\[
f'(x) = \left( \frac{\ln x}{x} \right)' = \frac{(\ln x)' \cdot x - x' \cdot \ln x}{x^2} = \frac{\frac{1}{x} \cdot x - \ln x}{x^2} = \frac{1 - \ln x}{x^2}.
\]

**Шаг 3.** Приравниваем производную к нулю:
\[
\frac{1 - \ln x}{x^2} = 0 \implies 1 - \ln x = 0 \implies \ln x = 1 \implies x = e.
\]
(При этом \(x \neq 0\)).

**Шаг 4.** Определяем знаки производной на интервалах:

- При \(x \in (0; e)\): \(f'(x) > 0\) (функция возрастает).
- При \(x \in (e; +\infty)\): \(f'(x) < 0\) (функция убывает).

**Шаг 5.** Так как при переходе через точку \(x = e\) производная меняет знак с плюса на минус, то \(x = e\) — точка максимума.
Значение функции в точке максимума:
\[
f(e) = \frac{\ln e}{e} = \frac{1}{e}.
\]

---

### Пример 2. Исследование функции \(f(x) = \frac{x}{1 + x^2}\)

**Шаг 1.** Область определения: \(\mathcal{D}(f): x \in \mathbb{R}\).

**Шаг 2.** Находим производную:
\[
f'(x) = \left( \frac{x}{1 + x^2} \right)' = \frac{x'(1 + x^2) - (1 + x^2)' \cdot x}{(1 + x^2)^2} = \frac{1 + x^2 - 2x^2}{(1 + x^2)^2} = \frac{-x^2 + 1}{(1 + x^2)^2}.
\]

**Шаг 3.** Приравниваем производную к нулю:
\[
\frac{-x^2 + 1}{(1 + x^2)^2} = 0 \implies -x^2 + 1 = 0 \implies x^2 = 1 \implies x = \pm 1.
\]

**Шаг 4.** Определяем знаки производной:

- При \(x \in (-\infty; -1)\): \(f'(x) < 0\) (функция убывает).
- При \(x \in (-1; 1)\): \(f'(x) > 0\) (функция возрастает).
- При \(x \in (1; +\infty)\): \(f'(x) < 0\) (функция убывает).

**Шаг 5.** Определяем экстремумы:

- \(x = -1\) — точка минимума, \(f(-1) = \frac{-1}{1 + 1} = -\frac{1}{2}\).
- \(x = 1\) — точка максимума, \(f(1) = \frac{1}{1 + 1} = \frac{1}{2}\).

---

### Пример 3. Исследование функции \(y = x^3 - 6x^2 + 5\)

**Шаг 1.** Находим производную:
\[
y' = 3x^2 - 12x = 3x(x - 4).
\]

**Шаг 2.** Находим критические точки:
\[
3x(x - 4) = 0 \implies x_1 = 0, \quad x_2 = 4.
\]

**Шаг 3.** Определяем интервалы монотонности:

- \(x \in (-\infty; 0)\): \(y' > 0\) — функция возрастает.
- \(x \in (0; 4)\): \(y' < 0\) — функция убывает.
- \(x \in (4; +\infty)\): \(y' > 0\) — функция возрастает.

**Шаг 4.** Вывод: \(x = 0\) — точка максимума, \(x = 4\) — точка минимума.

---

### Пример 4. Исследование функции \(f(x) = (x - 2)^2(x + 2)\)

**Шаг 1.** Находим производную по правилу произведения:
\[
f'(x) = ((x - 2)^2)' \cdot (x + 2) + (x + 2)' \cdot (x - 2)^2 = 2(x - 2)(x + 2) + (x - 2)^2.
\]

**Шаг 2.** Выносим общий множитель \((x - 2)\):
\[
f'(x) = (x - 2) \cdot \big(2(x + 2) + (x - 2)\big) = (x - 2)(2x + 4 + x - 2) = (x - 2)(3x + 2).
\]

**Шаг 3.** Находим критические точки:
\[
(x - 2)(3x + 2) = 0 \implies x_1 = 2, \quad x_2 = -\frac{2}{3}.
\]

**Шаг 4.** Определяем знаки производной:

- \(x \in (-\infty; -\frac{2}{3})\): \(f'(x) > 0\) — возрастает.
- \(x \in (-\frac{2}{3}; 2)\): \(f'(x) < 0\) — убывает.
- \(x \in (2; +\infty)\): \(f'(x) > 0\) — возрастает.

**Шаг 5.** Вывод: \(x = -\frac{2}{3}\) — точка максимума, \(x = 2\) — точка минимума.

---

### Пример 5. Нахождение асимптот функции \(f(x) = \frac{x^2}{x - 1}\)

**Шаг 1.** Область определения: \(\mathcal{D}(f): x \neq 1\).

**Шаг 2.** Проверяем вертикальную асимптоту при \(x = 1\):
\[
\lim*{x \to 1+0} \frac{x^2}{x - 1} = +\infty, \quad \lim*{x \to 1-0} \frac{x^2}{x - 1} = -\infty.
\]
Следовательно, \(x = 1\) — вертикальная асимптота.

**Шаг 3.** Ищем наклонную асимптоту \(y = kx + b\):
\[
k = \lim*{x \to \pm\infty} \frac{f(x)}{x} = \lim*{x \to \pm\infty} \frac{x^2}{x(x - 1)} = \lim*{x \to \pm\infty} \frac{x^2}{x^2 - x} = 1.
\]
\[
b = \lim*{x \to \pm\infty} (f(x) - kx) = \lim*{x \to \pm\infty} \left( \frac{x^2}{x - 1} - x \right) = \lim*{x \to \pm\infty} \frac{x^2 - x^2 + x}{x - 1} = \lim\_{x \to \pm\infty} \frac{x}{x - 1} = 1.
\]
Следовательно, \(y = x + 1\) — наклонная асимптота.

---

### Пример 6. Исследование функции \(f(x) = \frac{1}{x^2 + 1}\) (вторая производная)

**Шаг 1.** Первая производная:
\[
f'(x) = \left( (x^2 + 1)^{-1} \right)' = -(x^2 + 1)^{-2} \cdot (x^2 + 1)' = -\frac{2x}{(x^2 + 1)^2}.
\]

**Шаг 2.** Вторая производная (по правилу частного):
\[
f''(x) = -\left( \frac{(2x)'(x^2 + 1)^2 - (x^2 + 1)^2 \cdot (2x)}{(x^2 + 1)^4} \right) = -\left( \frac{2(x^2 + 1)^2 - 2(x^2 + 1) \cdot 2x \cdot 2x}{(x^2 + 1)^4} \right).
\]
Упрощаем:
\[
f''(x) = -\frac{2(x^2 + 1) - 8x^2}{(x^2 + 1)^3} = -\frac{2x^2 + 2 - 8x^2}{(x^2 + 1)^3} = -\frac{2 - 6x^2}{(x^2 + 1)^3} = \frac{6x^2 - 2}{(x^2 + 1)^3}.
\]

**Шаг 3.** Точки перегиба (где \(f''(x) = 0\)):
\[
6x^2 - 2 = 0 \implies x^2 = \frac{1}{3} \implies x = \pm\frac{1}{\sqrt{3}}.
\]
При переходе через эти точки \(f''(x)\) меняет знак, следовательно, это точки перегиба.

# 11. Выдержка из самых важных формул

- **Необходимое условие экстремума:** \(f'(x_0) = 0\).
- **Достаточное условие экстремума:** смена знака \(f'(x)\) при переходе через \(x_0\) (с \(+\) на \(-\) — максимум, с \(-\) на \(+\) — минимум).
- **Условие возрастания/убывания:** \(f'(x) > 0\) — возрастает, \(f'(x) < 0\) — убывает.
- **Условие выпуклости:** \(f''(x) > 0\) — выпуклость вниз, \(f''(x) < 0\) — выпуклость вверх.
- **Точки перегиба:** \(f''(x) = 0\) (или не существует) и меняет знак.
- **Вертикальная асимптота:** \(\lim\_{x \to a} f(x) = \infty \implies x = a\).
- **Наклонная асимптота \(y = kx + b\):**
  \[
  k = \lim*{x \to \infty} \frac{f(x)}{x}, \quad b = \lim*{x \to \infty} (f(x) - kx).
  \]
